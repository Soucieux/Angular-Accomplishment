# 🌌 Vision Canvas

> 一款私人自建的个人管理套件，基于 **Angular 21** 构建 —— 将影视追踪、财务提醒、开发日志与日常生活分析整合于一个统一、安全的界面中。

## ✨ 核心功能

| 模块 | 描述 | 状态 |
| :--- | :--- | :---: |
| **Today** | 每日规划器与时间块画布。<br>- 在按小时划分的网格日历上**拖拽创建**定时块<br>- **拖拽移动**以重新定位已有的时间块<br>- **拖拽调整大小**手柄以调整时间块时长<br>- 面向不定时任务的快速添加通道，支持键盘确认<br>- 带耗时计时器的**实时计时**会话<br>- 打开页面时自动滚动到当前时间指示线<br>- 提醒事项由 Reminder 模块实时注入，并在午夜自动刷新 —— 定时提醒显示在日历通道，未定时的提醒则以只读形式出现在快速添加通道 | 测试版 |
| **Home** | 围绕 *Life Clock*（生活时钟）构建的**轨道式仪表盘**，实时显示当前时间。<br>- **年、月、周、日**同心进度环<br>- 带实时计数的**卫星统计圆盘**（电影、补丁记录、语录、食谱）<br>- 玻璃质感面板组件：即将到来的提醒、待还款项、最近活动、影视类型分布、食谱列表以及收藏链接标签<br>- **周议程**视图与快捷操作胶囊按钮<br>- 完全自适应的移动端布局 | 使用中 |
| **Entertainment** | 面向**电影与电视剧**的媒体追踪器，支持丰富的元数据。<br>- **第三方 API** 查询标题、类型、演员表与封面图，并在评分或首播日期缺失时通过**抓取回退**补全<br>- Firebase / Cloudbase 图片存储与 CDN 分发<br>- **文字搜索**标题，另支持分类筛选、收藏切换与**颜色分级评分指示器**<br>- 完整的新增 / 删除历史记录与时间戳 | 稳定版 |
| **Reminder** | 支持实时云同步的账户支出追踪器。<br>- **行内单元格编辑**，支持键盘确认流程<br>- 颜色区分的进行中、已逾期与已还清状态指示器<br>- **开始 / 结束时间段** —— 每项可选填 HH:MM 时间范围，自动计算结束偏移量<br>- **单卡删除按钮**，快速移除单个条目<br>- **共享提醒**（仅限用户名 / 密码账号 —— 跨账号共享基于 CloudBase 实现）—— 标记为共享的项目会实时出现在已关联的账户上，附带仅共享筛选标签与创建者徽章<br>- 按用户持久化的状态 | 使用中 |
| **Portal** | 个人 AI 搜索中心与链接管理器。<br>- 面向 AI 工具发现的**标签式类别筛选**，附类别管理弹窗<br>- 支持类别分配的收藏链接管理；链接标题**自动首字母大写**，网站图标解析为**真实品牌标志**（Brandfetch，回退至普通图标）<br>- **日期计算器** —— 基于 CloudBase 持久化的日期区间运算；点击标题栏可折叠<br>- 共享链接标记，用于区分个人与共享条目<br>- 图标获取失败时的备用颜色头像 | 测试版 |
| **Debt Sonata** | 带完整还款历史的债务追踪画布。<br>- 支持人民币与加元的**卡片式账本**<br>- 预设与自定义**还款标签**，每张卡片附进度条<br>- 已还清状态的丝带样式与珊瑚色卡片配色<br>- 按币种汇总的统计卡片<br>- 每条记录的完整还款历史时间线<br>- 编辑条目时的**新周期**开关 —— 清空其还款记录并将余额重置以开启新周期 | 使用中 |
| **Resonance** | 个人语录库。<br>- 作者署名与时间戳<br>- 面向公开语录的**匿名浏览**支持<br>- 基于所有权的编辑与删除权限 | 使用中 |
| **Recipe** | 支持按分类配色主题的个人食谱本。<br>- 列表、详情与编辑器视图，窄屏下采用单列分页<br>- 带类型徽章与**中英双语名称**支持的**食材分组**；步骤文字中匹配的食材名称会自动高亮为标签<br>- 实时**份量缩放器**与分步骤操作视图<br>- 分类配色主题 —— *玫瑰红 · 绿色 · 紫色 · 琥珀色 · 粉色*<br>- 拖拽重排步骤 | 使用中 |
| **Patch Notes** | 内部开发日志，包含两种视图。<br>- *Patch Notes*（Sprint 日志）—— 按组件新增、编辑、删除条目；每条附漏洞标记；状态筛选（进行中 / 已解决）；分页显示，并在按日期排序后正确重算行合并（rowspan）<br>- 统计条上的**活动热力图**弹窗 —— 展示跨年度的月度条目数量，附强度分级与语言感知的月份标签<br>- *Release Notes*（发行日志）—— 带版本卡片、分节标题、徽章标签与摘要的发布记录 | 使用中 |
| **Account** | 采用海军蓝天空主题的个人账户管理中心。<br>- 身份卡片 —— 用户名编辑与带已验证徽章的邮箱展示<br>- 带强度指示与可见性切换的密码修改<br>- **Second Brain 统计** —— 电影、提醒、债务与食谱的实时计数<br>- 带连接线与颜色区分日期的里程碑时间线<br>- **已关联账户**（仅限用户名 / 密码账号 —— 账号关联基于 CloudBase 实现）—— 通过关联码关联另一账户、批准或拒绝请求、断开或重新关联；与已关联账户共享提醒<br>- **节奏**面板，用于设置离开保险箱后多久内保持解锁状态（每次都需要、固定分钟数或直到重新加载）<br>- 危险区域卡片，支持带确认防护的账户删除，以及在忘记口令时**删除保险箱口令**（未设置口令时按钮呈灰色，保留你的保险箱数据） | 使用中 |
| **Login** | 身份验证入口。<br>- 各平台均支持邮箱 / 密码登录，另在**浏览器与已安装的网页应用**上提供 **Google 登录**（移动端与桌面端）—— Tauri 桌面端与 iOS 原生应用中暂不显示，因其尚不支持该功能<br>- 面向新用户创建账号的流程，附邮箱验证码与实时密码强度检查清单<br>- **忘记密码** —— 基于邮箱验证码的重置流程<br>- 保护所有已认证页面的路由守卫<br>- 登录后重定向至上次访问的路由<br>- 侧边栏在线状态行：头像、在线状态与账户菜单弹窗 | 稳定版 |
| **About** | 职业履历时间线。<br>- 可交互的里程碑条目<br>- **动态渐变背景** | 稳定版 |
| **Vault** | 采用 **Slate Steel**（钢青灰）主题的账户关联关系图谱。<br>- **口令保护** —— 首次访问时设置口令，之后需输入口令方可解锁<br>- 账户（按类别着色的应用图标节点 —— **归属多个类别时分段着色**）、邮箱（圆形）、电话（菱形）与链接（六边形）的**力导向图**<br>- **点击追溯** —— 按跳数（直接 / 二度关联）高亮关联节点并淡化其余部分；支持拖拽、平移与缩放<br>- **类别概览**标签，支持**行内重命名 / 删除**，并新增统计已验证账户并可作筛选的**已验证**标签；**图例即类型筛选** —— 点击某一类型（或"已验证"）即可仅显示该类型，再次点击取消<br>- **预设 + 自定义类别** —— 五个内置预设（交通 · 财务 · 社交 · 购物 · 通用），各具唯一颜色与图标，另可自建<br>- **添加账户弹窗**，支持**多选类别**、同名校验与多重关联连线；**关联模式**用于手动关联节点<br>- **非账户标识符** —— 两步式向导还可添加独立的邮箱、电话或备注条目，并将其关联至另一标识符作为**备用**（图谱中以虚线连接）<br>- **集中式节点操作** —— 图谱中账户仅用于建立关联；非账户节点通过编辑名称弹窗重命名或删除，账户则在列表视图中编辑<br>- **地图自动适配** —— 打开时自动框选所有节点，随图谱增大逐级缩小基础比例；支持**行内编辑账户名称**<br>- 列表视图支持行内链接编辑、**多类别分配**与**自由格式备注关联**（不显示于图谱）；窄屏下图谱替换为使用**列表视图**的提示；按用户持久化于 CloudBase | 测试版 |

### 🚀 R2 —— 打磨与优化（2026 年 6 月至今）

## 🔐 身份验证与数据后端

应用在**每个会话中运行于两个独立后端之一**，由*登录方式*决定。两个后端始终初始化，以便登录页可提供任一方式；当前数据后端在登录时确定，并在该会话中保持。

| 登录方式 | 认证提供方 | 数据后端 |
| :--- | :--- | :--- |
| **用户名 / 密码** | 腾讯云开发 CloudBase | **CloudBase**（默认） |
| **Google** | Firebase Auth | **Firebase**（实时数据库 + 存储） |

> 两份数据**完全独立** —— 同一个人以两种方式登录会得到两份互不相干的数据。Google 登录**仅在浏览器与已安装的网页应用**（移动端与桌面端）上提供；在桌面（Tauri）与 iOS 原生应用中隐藏，这些平台仅支持用户名 / 密码登录。

### 各后端的功能可用性

下表未列出的功能在两个后端上表现**完全一致**：电影、提醒、食谱、Portal 链接、债务、保险箱、语录、补丁 / 发行日志、Today、活动动态、按用户统计与实时计数、里程碑、偏好设置，以及保险箱口令门禁。

| 功能 | CloudBase（密码） | Firebase（Google） | 原因 |
| :--- | :---: | :---: | :--- |
| 已关联账户 | ✅ | ❌（隐藏） | 跨账户关联是基于 CloudBase 的功能 |
| 共享提醒 | ✅ | ❌ | 同为跨账户限制 |
| 管理员角色 | ✅ | ❌（永不） | 角色是 CloudBase 的概念 |
| Resonance —— 删除语录 | 仅管理员 | ❌ | 受管理员权限限制；Firebase 无管理员 |
| Portal —— 日期计算器 | 仅管理员 | ❌ | 受管理员权限限制 |
| 编辑 / 删除**他人**数据 | 仅管理员 | ❌（仅限本人数据） | Firebase 无管理员提权 |
| 修改密码 | ✅ | ❌（隐藏） | Google 账号没有密码 |
| 删除账号的确认方式 | 密码确认 | Google 重新验证弹窗 | 身份证明方式不同 |
| 匿名浏览公开语录 | ✅ | ✅（由 CloudBase 提供） | 共享基础设施，与后端无关 |

### 存储结构差异

| 方面 | CloudBase | Firebase 实时数据库 |
| :--- | :--- | :--- |
| 数据库类型 | 文档 / 集合存储，支持服务端查询 | JSON 树 —— 读取时拉取整个集合并在**客户端**筛选 |
| 所有权字段 | `_openid`（由平台自动标记） | 原生 `uid`（读取时在内存中以 `_openid` 形式呈现给应用） |
| 按用户文档 | `users` 集合 —— 每位用户一份文档 | `users/<uid>` 节点 |
| 日期计算器 | 共享集合中按所有者划分的行 | 专属路径 `date_calculator/<uid>` |
| 保险箱口令哈希 | CloudBase 云函数 + 集合 | 经 Firebase Functions 存于 `passphrase_locks/<uid>`（客户端仅得到布尔值） |
| 电影图片 | 腾讯云 COS + CDN | Firebase 存储 |
| URL 代理（Portal RSS / 标题） | Express 端点 + `fetchUrl` 函数 | `proxyFetch` 可调用云函数 |

其中 **RTDB「无服务端查询」** 是唯一具有实际影响的一点：Firebase 读取会拉取整个集合并在客户端筛选 —— 在个人规模下没有问题，但在大规模下会有影响。

## 🚀 快速开始

### 1. 克隆仓库

```bash
git clone https://github.com/Soucieux/Angular-Accomplishment.git
cd Angular-Accomplishment
```

### 2. 安装依赖

```bash
npm install
```

### 3. 配置环境变量

复制环境变量模板并填入您的凭证：

```bash
cp src/environment/environment-template.ts src/environment/environment.ts
```

打开 `src/environment/environment.ts`，填入您的 CloudBase `envId`（默认的用户名 / 密码后端）与 Firebase 配置对象（Google 登录 + Firebase 后端）。将 `authDomain` 设为服务应用的域名。

### 4. 启动开发服务器

```bash
ng serve
```

访问 `http://localhost:4200`。应用会在文件变更时自动重新加载。

### 5. 部署

线上站点由 **Firebase Hosting** 提供服务；Firebase 后端还承载云函数与实时数据库安全规则，因此三个目标需一并部署：

```bash
ng build
firebase deploy --only functions,database,hosting
```

| 目标 | 部署内容 |
| :--- | :--- |
| `functions` | 保险箱口令锁可调用函数 + `proxyFetch` URL 代理 |
| `database` | `database.rules.json` —— RTDB 安全规则（`passphrase_locks` 拒绝规则确保客户端无法读取哈希） |
| `hosting` | 构建后的 Angular 应用 |

> **Google 登录配置**（一次性，在 Firebase 控制台）：启用 **Google** 登录提供方，将服务域名保留在**身份验证 → 授权域名**中，并将 `environment.ts` 中的 `authDomain` 设为该服务域名 —— 当二者不一致时，Chrome M115+ 会阻断登录流程。
